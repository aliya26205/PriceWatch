# 📈 PriceWatch

PriceWatch is a web-based application that helps users monitor product prices and receive notifications when prices change. It provides an easy way to track products, compare prices, and manage price history through a simple and responsive interface.

---

## 🚀 Features

- 🔐 User Registration and Login
- 📦 Add and Manage Products
- 💰 Track Product Prices
- 📊 Dashboard with Product Information
- 🔍 Search and Filter Products
- 📱 Responsive User Interface
- 🗂️ Organized Product Management

---

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/aliya26205/PriceWatch.git
```

2. Open the project folder.

3. Import the MySQL database.

4. Configure the database connection.

5. Run the project using XAMPP or any PHP-supported local server.
